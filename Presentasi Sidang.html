Implementasi FSM pada NPC Pemandu
BAB I · PENDAHULUAN

Orientasi kampus konvensional kurang efektif

  • Tur fisik bersifat satu arah — retensi mahasiswa baru terhadap letak & fungsi fasilitas rendah
  • Peserta dalam jumlah besar → tidak semua mendengar informasi secara optimal
  • Materi tur tidak sinkron dengan perubahan fisik kampus (gedung baru, renovasi)
  • Mahasiswa baru dari luar kota berisiko disorientasi sejak hari pertama kuliah

Solusi yang Diusulkan

Simulasi interaktif berbasis mobile dengan NPC pemandu Widy yang berperilaku adaptif — dapat diakses kapan saja, di mana saja, dan mudah diperbarui.

BAB IV · IMPLEMENTASI TEKNIS

Logika Transisi pada Update()

void Update() {
  float distance = Vector3.Distance(
    transform.position, player.position);
  float playerSpeed = player.GetComponent<CharacterController>().velocity.magnitude;
  bool playerIsMoving = playerSpeed > 0.3f;

  if (distance <= 2f || !playerIsMoving) {
    currentState = State.Waiting;
  } else if (distance <= 5f) {
    currentState = State.Follow;
  } else {
    currentState = State.CatchUp;
  }
  ApplyState(currentState);
}
  • Skrip WidyCompanionFollower.cs mengevaluasi jarak Euclidean & kecepatan pemain setiap frame
  • NavMesh di-bake pada seluruh permukaan lantai yang dapat dilalui
  • Area Trigger dipasang pada 21 area menggunakan Box Collider (Is Trigger)
  • Desain dialog bergaya visual novel memperkuat kesan personal saat interaksi

⚡ ARGUMEN KUNCI

Mengapa FSM diuji dengan SUS & UEQ?

Dua Lapis Pengujian yang Saling Melengkapi

🔧 Pengujian Fungsional (Black Box)

  • Menguji kebenaran teknis: transisi state, navigasi, deteksi trigger
  • Menjawab: "Apakah FSM bekerja sesuai rancangan?"
  • Bukti: Akurasi 100%, response time terukur, success rate 100%

👤 Pengujian Pengguna (SUS & UEQ)

  • Mengukur penerimaan pengguna: kemudahan & pengalaman
  • Menjawab: "Apakah pengguna menerima aplikasi ini?"
  • FSM adalah alat; SUS/UEQ adalah bukti bahwa alat tersebut bermanfaat bagi pengguna

✅ Fokus penelitian adalah NPC Pemandu (bukan musuh) → tujuan akhirnya adalah pengalaman orientasi yang positif. Kedua pengujian saling memperkuat.
